# ⚡ n8n Workflows Collection

A collection of automation workflows built using n8n.

## 📦 Projects Included

### 🤖 Telegram Bot

* Automated Telegram chatbot
* Workflow-based responses
  👉 See: `/telegram-bot`

### 💬 WhatsApp Bot

* Automated replies and messaging
  👉 See: `/whatsapp-bot`

### 🧠 AI Agent

* AI-powered automation workflow
  👉 See: `/ai-agent`

## 🚀 How to Use

1. Install n8n
2. Open dashboard
3. Import any workflow JSON
4. Add your credentials
5. Activate workflow

## 🔐 Security

* No API keys included
* No credentials shared
* Use your own tokens inside n8n

## 🛠️ Built With

* n8n
* APIs (Telegram, OpenAI, etc.)

## 📌 Notes

Each project has its own folder with:

* Workflow JSON
* Setup instructions
