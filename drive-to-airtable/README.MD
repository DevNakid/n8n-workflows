# n8n Google Drive → Email → Airtable

## 🚀 Workflow Description

This automation does:

1. Detect new file in Google Drive
2. Send file via email
3. Save file details in Airtable

## 🧰 Tools Used

* n8n
* Google Drive
* Airtable
* Email (SMTP / Gmail)

## ⚙️ Setup

1. Import the workflow JSON into n8n
2. Add credentials:

   * Google Drive
   * Airtable
   * Email
3. Select your Google Drive folder
4. Set recipient email
