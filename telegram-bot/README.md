# 🤖 Telegram Bot (n8n Workflow)

This project is a Telegram chatbot built using n8n (workflow automation tool) without traditional coding.

## 🚀 Features

* Automated Telegram responses
* Workflow-based logic (no code)
* Easy to modify and extend
* Integration-ready (APIs, webhooks, etc.)

## 🛠️ Built With

* n8n
* Telegram Bot API

## 📦 Workflow File

The bot logic is stored in:

telegram-bot-workflow.json

## ⚙️ How to Use

1. Install n8n
2. Open n8n dashboard
3. Import the workflow JSON file
4. Configure your credentials:
   * Telegram Bot Token
5. Activate the workflow

## 🔐 Credentials

⚠️ This repository does NOT include:

* Telegram Bot Token
* API keys

You must add your own credentials inside n8n.

## ▶️ Run

After importing and adding credentials:

* Activate the workflow
* Your bot will start responding automatically
